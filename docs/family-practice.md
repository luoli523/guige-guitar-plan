# 爸爸与瓜仔练琴打卡

两人共用原有 12 周课程，各自完成、撤销；课程难度尚未针对儿童改编。课程第 1 天与真实星期几独立。顶部显示实际日历周、日期和全课程完成数量。徽章按真实练琴日期累计 7、14、28 天解锁，不代表连续天数。共同练琴数是双方打卡日期的交集。

顶部七格按新加坡时间排列真实周一到周日：实色勾选为已练，外框标记今天；开始前、未来日期不可操作。点击日期可打卡、补记或撤销；可回看以前的周。用户确认 2026-10-23 周五是双方第一次练习，升级时将已有无日期课程记录的成员映射为该日一次日期打卡，不伪造周一到周四记录；原课程记录不变。无旧记录的成员不会自动打卡。日期数据保存后不会重复迁移。

日期记录独立存入 `guige-guitar-calendar-v1`。完成课程自动计入操作当天，同一天完成多课只累计一天；撤销课程不撤销实际练习日期，日期可在顶部独立调整。切换课程不会切换日历。页面每 30 秒及重新获得焦点时更新今天。

记录保存在当前浏览器的 `guige-guitar-family-progress-v2`，不提供跨设备同步。首次读取时将旧 `guige-guitar-plan-completed` 中有效记录归入爸爸；旧键保留作为备份，新记录优先。首次打卡后保存双人数据。清除浏览器数据会删除这些记录。

配图：`public/family-guitar-hero.webp`，使用内置 imagegen 生成，以 gua-story 的 dad_guitar_v3.png 与 guagua_sheet_v2.png 为人物参考。旧配图保留。头像以 CSS 显示新配图的父子局部。

生成提示：暖色 16:9 父子练琴插画，爸爸保留黑发、矩形眼镜、深色 T 恤与米色长裤，弹原声吉他；瓜仔保留短黑发、灰色 T 恤、蓝色短裤，弹较小的蓝色电吉他。两人并排坐在家中温暖的音乐角互相鼓励。匹配参考图的精致动漫手绘风格，奶油色、琥珀光与柔和绿色。人物与琴完整居中、留舒适边距，无头巾、文字、商标或水印。

验证：`npm test`、`npm run lint`、`PAGES_BASE_PATH=/guige-guitar-plan npm run build`。手动检查父子分别打卡、撤销、刷新恢复、训练周切换和手机布局。
